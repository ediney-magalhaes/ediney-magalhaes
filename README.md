# Olá, sou Ediney Magalhães! 👋

Bem-vindo(a)! Sou **Estatístico** e Especialista em **Health Analytics** com mais de 12 anos de experiência no setor de saúde. 

Atualmente, atuo na interseção entre **Qualidade Hospitalar** e **Engenharia de Dados**, construindo pipelines de dados (ETL), implementando culturas *Data-Driven* e desenvolvendo modelos de Machine Learning (MLOps) para resolver problemas reais de negócio.

---

### 🚀 O que eu faço

Transformo departamentos baseados em processos manuais em ecossistemas de dados inteligentes.

- 🏥 **Health Analytics:** Análise estatística de indicadores hospitalares e segurança do paciente.
- ☁️ **Engenharia de Dados:** Migração de dados locais para Cloud (**Google BigQuery**) e automação de pipelines.
- 🤖 **Data Science:** Modelagem preditiva e classificação de prontuários (codificação) com foco em auditoria médica.
